📌 Descripción del Proyecto

Midas Online es una plataforma web simulada de banca digital, desarrollada como proyecto final de Programación III, siguiendo la metodología Agile-Scrum.

Objetivos del proyecto

Crear un login seguro y funcional.

Desarrollar un dashboard interactivo con balances ficticios, gráficos dinámicos y panel lateral.

Implementar modo claro/oscuro y efectos visuales modernos (degradados dorados, animaciones, efectos 3D).

Automatizar pruebas funcionales y generar reporte HTML de evidencia visual.

Alcance del proyecto

Funcionalidades de banca digital simulada.

Visualización de gráficos y estadísticas financieras ficticias.

Responsividad y accesibilidad en diferentes dispositivos.

No se maneja dinero real ni conexión a bancos reales.

🧪 Plan de Pruebas y Automatización

Requerimientos funcionales: login, navegación dashboard, visualización de gráficos, modo claro/oscuro.

Requerimientos no funcionales: accesibilidad, responsividad, velocidad de carga y consistencia visual.

Criterios de aceptación/rechazo: Cada prueba se considera exitosa si la acción se completa correctamente y se captura evidencia visual.

Herramientas: Selenium WebDriver en Python, generación de reporte HTML.

Cronograma de pruebas: pruebas manuales y automatizadas ejecutadas del 13/08 al 17/08.

Plantillas y documentación: evidencia visual incluida en HTML.

Responsables: Autora única ejecutando todas las pruebas.
